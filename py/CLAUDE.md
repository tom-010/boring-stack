# Python Service (py/)

Internal FastAPI service called by the TypeScript app via typed RPC. Not a REST API. Not exposed to browsers.

## Philosophy

Boring is better. Maximum utility via minimum syntax. Duplication over premature abstraction. Design for 10 users. Optimize for the programmer's working memory, not CPU cycles. Silent on success, stderr on error.

## Stack

- **Runtime:** Python 3.12+
- **Framework:** FastAPI (RPC endpoints, not REST resources)
- **ORM:** SQLAlchemy 2.0 (mapped classes, `select()` API)
- **Database:** PostgreSQL (shared with Prisma — schema owned by Prisma, Python reads/writes via SQLAlchemy)
- **Package manager:** uv (never pip)
- **Linter/formatter:** ruff
- **Type checker:** mypy

## Layout

```
app/app.py      FastAPI application, Pydantic models, endpoints
app/models.py   SQLAlchemy models (generated by sqlacodegen, do not edit manually)
app/db.py       Engine, session factory, get_db() dependency
app/logger.py   Logging configuration
Makefile         Dev commands
pyproject.toml   Dependencies and tool config
```

## Commands

```bash
make dev          # Start dev server (uvicorn --reload on port 8123)
make typecheck    # Compile check + mypy
make lint         # ruff check
make fmt          # ruff format + auto-fix
uv add <pkg>     # Add a dependency (never pip install)
uv sync           # Install from lockfile
```

## Database

- **Schema is owned by Prisma** (in `../prisma/schema.prisma`). Never create or alter tables from Python.
- **Connection:** `DATABASE_URL` env var, defaults to `postgresql://app:app@localhost:5432/app`.
- **Models:** Generated by sqlacodegen into `app/models.py`. Regenerate after Prisma schema changes:
  ```bash
  uv run sqlacodegen postgresql://app:app@localhost:5432/app > app/models.py
  ```
  Then run `make fmt` to normalize the output.
- **SQLAlchemy 2.0 style only.** Use `db.execute(select(...))` — never the legacy `db.query()` API.
  ```python
  from sqlalchemy import select, func
  from models import Todos

  # Good: 2.0 style
  count = db.execute(select(func.count()).select_from(Todos).where(Todos.user_id == uid)).scalar_one()
  rows = db.execute(select(Todos).where(Todos.completed == False)).scalars().all()

  # Bad: legacy 1.x style — do not use
  db.query(Todos).filter(...)
  ```
- **Session injection:** Use `Depends(get_db)` in endpoint signatures.

## Coding Standards

- **All endpoint functions must be fully typed.** Explicit parameter types and return types. No `Any`, no missing annotations.
- **Pydantic models** for all request/response bodies. Define them in `app/app.py` alongside the endpoints.
- **No REST resources.** Endpoints are verbs/actions (e.g., `/resize`, `/todo-count/{user_id}`), not CRUD resource routes.
- **Co-location:** Keep models and endpoints together in `app/app.py` unless the file gets unmanageable.
- **No tests unless explicitly asked.** DO NOT abstract code until it is used 3 times.
- **Logging:** Use `logging.getLogger("app")`. No emojis, no cute messages.

## TypeScript Integration

This service is called from TypeScript loaders/actions via a generated SDK. After changing endpoints:

1. Make your changes in `app/app.py`
2. Run `make typecheck` to verify Python types
3. Run `../scripts/sync-py.sh` from the project root to regenerate the TypeScript SDK
4. The TypeScript side imports from `~/lib/py/client`

The type pipeline: Pydantic models -> FastAPI OpenAPI schema -> `@hey-api/openapi-ts` -> TypeScript types.

## Verification

- Run `make typecheck` after changes.
- Run `make fmt` to auto-fix lint issues.
- Test endpoints with curl: `curl -s http://localhost:8123/hi`
- Port 8123. If blocked, kill it: `../scripts/killport.sh 8123`
